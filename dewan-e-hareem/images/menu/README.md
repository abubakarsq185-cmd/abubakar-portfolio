# Dish photos — "magic image" slots

Every menu item has an image slot. To add a real photo for a dish, drop a
JPG here named with the item's menu number:

    images/menu/<number>.jpg

Examples:
- Chicken Malai Boti  → images/menu/36.jpg
- Chicken Karahi      → images/menu/68.jpg
- Hareem Special Pizza→ images/menu/30.jpg

The photo appears automatically on that dish card. Until a photo is added,
a gold emblem placeholder is shown. Recommended: square-ish JPG, ~800×600,
under ~300 KB. No code changes needed — just add or replace the file.
